# PUBG Interactive Map v26.5.17

**PUBG 배틀그라운드 인터랙티브 맵 도구**

Made by **LEEJUNHO** (2026)

---

## 🎮 주요 기능

- **5개 맵 지원**: 에란겔, 미라마, 비켄디, 태이고, 론도
- **차량/보트 스폰 위치**: 에란겔 329개 차량 스폰 (이미지 분석 추출)
- **비밀의 방**: 미라마15개 에란겔 15개, 태이고 15개, 비켄디 10개, 론도 15개
- **낙하산 계산기**: 비행선에서 700m 점프 지점 자동 계산 (정사영 + 피타고라스)
- **거리 측정 도구**: 두 지점 클릭으로 거리 측정
- **그리드 시스템**: 1000m/100m 단위 격자

---

## 📐 좌표계

- **1 unit = 1m** (예: x:100, y:100 = 100m 지점)
- 에란겔/미라마/태이고/론도: 8000x8000
- 비켄디: 6000x6000
- Leaflet CRS.Simple 사용
- y축 반전 주의: `L.marker([S - loc.y, loc.x])`

---

## 🔧 기술 스택

- **Leaflet.js**: 지도 라이브러리
- **Vanilla JavaScript**: 프레임워크 없이 순수 JS
- **Base64 이미지**: 모든 맵 이미지 내장
- **CSS Variables**: 다크 테마 구현
- **Responsive Design**: 모바일 최적화

---

## 📊 데이터 출처

- **차량 스폰 (에란겔)**: pubgmap.io 이미지에서 OpenCV로 329개 추출
- **비밀의 방**: 직접 확인 및 좌표 추출
- **맵 이미지**: 고해상도 JPEG 2048x2048로 최적화
